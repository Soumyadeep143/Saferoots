STEP 1: Create GitHub Repository
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open: https://github.com/new
2. Enter:
   Repository name: SafeRoots
   Description: Gamified platform for information literacy
   Visibility: Public (NOT private)
3. Click "Create repository"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Push Code to GitHub
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy & paste these commands in terminal:

  cd /tmp/saferoots-demo
  
  git remote add origin https://github.com/YOUR_USERNAME/SafeRoots.git
  
  git branch -M main
  
  git push -u origin main

IMPORTANT: Replace "YOUR_USERNAME" with your actual GitHub username!

After pushing, you'll see:
  ✓ Counting objects...
  ✓ Writing objects...
  ✓ Done!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: Deploy to Vercel
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A: Web Dashboard (EASIEST - 1 click)
─────────────────────────────────────────

1. Open: https://vercel.com/new
2. Click "Import Git Repository"
3. Paste your GitHub URL:
   https://github.com/YOUR_USERNAME/SafeRoots
4. Click "Import"
5. Click "Deploy" 
6. Wait ~1 minute...
7. ✨ DONE! You'll get a live URL like:
   https://saferoots-abc123.vercel.app

Option B: Vercel CLI
─────────────────────

  npm install -g vercel
  cd /tmp/saferoots-demo
  vercel
  # Follow the prompts

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: Verify It's Live
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Click the Vercel URL (or copy from dashboard)
2. Test all features:
   ✓ Click "Scam or Safe?" tab → Take a quiz
   ✓ Click "Fact-Check Map" → Explore locations
   ✓ Click "Media Decoder" → View outlets
3. Try on mobile (tap menu icon)
4. Share the URL with others!

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Repository not found"
   → Check YOUR_USERNAME is correct
   → Make sure repo is PUBLIC (not private)

❌ "Build failed on Vercel"
   → Check node_modules in local build: npm run build
   → Verify package.json has all dependencies
   → Check vercel.json config

❌ "Blank page after deploy"
   → Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
   → Check browser console (F12) for errors
   → Verify all assets loaded in Network tab

❌ "Map not showing"
   → This is expected in demo - uses mock data
   → Check browser console for Leaflet errors
   → Verify internet connection
